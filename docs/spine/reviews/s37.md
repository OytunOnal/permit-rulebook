**What the build changed from the approved words, said here so the human reads it.** Point 1 said the page tells an arrival from a reload by the navigation's type. The build measured that a restored arrival which is then reloaded, or left and returned to, reads `reload` / `back_forward` while the browser still holds only the arrival — the approved design would have sent the screen's Back off the site in exactly those cases. The page therefore writes where its held entries begin into every entry's state and reads it back; the type is only the fallback for entries written before this slice. Confirmed independently by the Spec axis (a type-only variant fails the reloaded and returned arrival). The change is strictly safer and adds no promise to "What a reader gets", but the approval was given to different words.

## Open lines

open with reason: src/lib/screen.ts:321-328 @ 8d1b451 — `firstHeld` is kept as a fixed step number, so when the record grows in another tab the rebuilt list is longer than the one the state was written against: tab A arrives on three answers, tab B (same origin) answers two more, tab A reloads — state `{step:5, firstHeld:3}`, 5 > 3, and the screen's Back calls `history.back()` onto the page the reader came from. Reproduced at both shas by the Security axis (base and head both land on `/data/`). Live instance: yes — the exact fault the slice fixes, through a second tab. Fixed in delta 1 with its round: carry how many steps the browser holds behind the current one, not where they began.
open with reason: src/lib/screen.ts:323-326 @ 8d1b451 — a bad or missing `firstHeld` falls toward "go back in the browser" rather than toward an arrival: a string, `{}`, a negative, `-Infinity`, `0`, or an entry written by the previous build (`{step}` only) after a reload all resolve to 0 and the screen's Back leaves the site; `NaN` sticks as `NaN`. Only a same-origin script can write `history.state`, so there is no outsider path; the real case is a reader with an arrival tab open across the deploy who reloads. Fixed in delta 1: only an integer is believed, anything else is an arrival — the safe side, because stepping in place never leaves the site.
