# Naming — release gate, round 1

Generated 2026-09-06 at the s6 boundary. Four `analyst` agents on Opus, one per
direction, each blind to the others and to this file. **No availability lookups
in this round** — that is round 3, on survivors only.

The graveyard below is the point of this file: a candidate that died here must
not be re-proposed next week without someone reading why it died.

## The brief they worked from

The one-pager: problem, user (a knowledge worker outside the EU, often reading a
second language, often anxious, often on a phone), positioning ("an open
work-permit ruleset carrying a date and a verbatim official quote on every
value"), and the planned waves (v1 DE/FR/ES/NL → CA+AU → rest of Europe), so a
name encoding "EU" or "four countries" ages into a lie.

**A finding all four directions reached independently:** the working name is not
merely unchosen, it is *wrong*. This product is about work and residence
permits. A visa is a different instrument. "visa-navigator" misdescribes the
product in its own title.

## Direction 1 — the tool

*Names for the instrument: what it does, the act of checking.*

| Candidate | Verdict |
|---|---|
| **Gapcheck** | Defended 1st. Names the actual output (the gap), never promises eligibility, spellable cold, gets *more* accurate in wave 2 (points systems have gaps). Risk: it is a feature name — it shrinks if the project's centre moves to the dataset. |
| **Test Fit** | Defended 2nd. Gentlest option: a verdict on the *fit*, not on the person. A2 vocabulary, trivially spellable. Two words, soft as an identity; suspected collision with architecture software. |
| **Rulecheck** | Defended 3rd. Tells the HN/GitHub room in one word that there is an open ruleset and a deterministic engine. Colder and faintly authoritarian for the anxious reader. |
| Permit Check | The honest baseline; highest search comprehension, corrects the visa error. But it is a label, not a name — unownable, and plain enough to be mistaken for a government service. |
| Caliper | Perfect metaphor (measures the distance between two surfaces); killed by spelling — US *caliper* vs UK *calliper* splits the word in half. |
| Rangefinder | "Measures distance to the target, has no opinion about you" — good stance. Long; rifle/golf association. |
| Plumbline | Best idea (an instrument with no opinion), fatal execution: the silent *b*. Steal it for the tagline. |
| Level | Warm and short, but "levelling up" is the wrong register, and a bare high-frequency word is unfindable. |
| Reckoner | *Ready reckoner* is British, dated, unknown to L2 readers; Radiohead owns the search results. |
| Tally | Under-describes v1 (thresholds are not accumulations); Turkish *tali* = "secondary" is unlucky. |
| Sift | Mishears as shift/sniffed on a bad line; "sifting" discards the user's options. |
| Dry Run | Kind framing (a rehearsal, no consequences) but a native-speaker idiom. |

**Ceiling of the direction:** a tool name describes the *replaceable* half. Anyone
competent can ship a checker; the dated, quoted, open ruleset is the half nobody
else has. Instrument names also earn trust without earning affection — passed on
with a shrug rather than a recommendation.

## Direction 2 — the dataset

*Names that put the open, dated, source-quoted corpus at the centre.*

| Candidate | Verdict |
|---|---|
| **Work Permit Sourcebook** | Defended 1st. States the differentiator in two ordinary words — *source*. Warm to a frightened reader, technical to a developer, hosts a verb ("look it up in the Sourcebook"). Risk: "book" implies bound, finished, static — it hides the daily watch, the best engineering here. |
| **Work Permit Register** | Defended 2nd. Plainest institutional word, a near-cognate in all four v1 languages. Wound: *register* also means to enrol — an anxious reader may hear "I am being recorded", which fights the on-device privacy promise. |
| **Work Permit Almanac** | Defended 3rd. The only one with personality, and the annual-tables-of-dated-numbers metaphor is a description, not a stretch. But an almanac publishes yearly; the daily re-fetch is what nobody else has. |
| Permit Ledger | Maps the append-only history exactly, and developers read the provenance model off the name. No cognate in any v1 language; blockchain smell near a privacy claim. |
| Permit Gazette | All four countries publish rule changes in an official gazette, and this watches them. But an unofficial project wearing a state journal's name invites the accusation it dresses as government. |
| Permit Atlas | Anticipates waves 2–3 (more plates); true global cognate. Software is thick with Atlases; sets a map expectation the questionnaire does not meet. |
| Permit Commons | Best encoding of the governance promise. No cognate, hard English word, NGO tone, hosts no verb. |
| The Permit Record | Killed by a false friend in the v1 market: German/Dutch *Rekord* means an achievement, not a document. |
| Permit Tables | Easiest possible read; barely a name, and it strips out the one thing that distinguishes the tables — that every cell is dated and quoted. |
| Routebook | Warm, memorable, *route* is the domain's own noun and a cognate. But routes read as travel to everyone outside the domain. |
| As Of | The sharpest statement of the differentiator, and it fails everything else — no noun, no domain signal, cannot host a tool name. Kept to mark where the direction stops working. |
| Ground Truth | Flattering and legible to developers; but it is a self-awarded title — every stale threshold then reads as hypocrisy. |

**Ceiling of the direction:** it buys standing with contributors, journalists and
tool-builders, and pays in the comprehension of the person typing "am I eligible
for the German Blue Card". It also risks leaving the consumer tool nameless.

## Direction 3 — the promise

*Names carrying the stance: quoted, dated, checkable, not for sale.*

| Candidate | Verdict |
|---|---|
| **Verbatim** | Defended 1st. Names the exact differentiator; promises a *method*, not an outcome, so it stays true when a value goes stale. Latin root carries into Romance languages; opaque to Turkish/Hindi/Mandarin readers. Suspected 40-year-old consumer brand for blank media — trademark question is real. |
| **Footnote** | Defended 2nd. Does not claim honesty, names the *artifact* of it. Translation-stable object everywhere. But "a footnote in history" means unimportant — it diminishes a life decision. |
| **Says Who** | Defended 3rd. The literal question the product answers, asked from the reader's side. Idiomatic; may read confrontational to an anxious L2 reader. |
| Word for Word | The best meaning, one of the worst strings — three plausible spellings from one hearing, and transcription services own the phrase. |
| Good Faith | Near-direct calque in every v1 language. But it is a legal term of art in immigration, and the most sanctimonious-sounding option — the audience is pre-immunised against exactly that. |
| Plainly | Contemporary and gentle; homophone "planely" in a migration context is an expensive accident. |
| On the Record | Argues with its own product: a privacy-first tool named after record-keeping, in a domain where "your record" means something frightening. |
| Firsthand | Calm and clear; firsthand/first-hand/first hand is three URLs from one hearing. |
| See For Yourself | Warmest, and semantically the whole product. Three words, nearly unfindable in search. |
| Not Advice | The most radically honest, and camouflage — "not legal advice" is boilerplate on every immigration page. Reads to a scared phone reader as "this will not help you". |
| Second Opinion | Fits the real usage (checking what a recruiter told you), but promises an *opinion*, the one thing the product refuses to give. |
| Nothing to Sell | The most relevant sentence for a burned audience, with an expiry date: sponsorship or a paid tier turns the name into an accusation. |

**Ceiling of the direction:** lead-gen sites also call themselves honest and
transparent. A promise-name spends its first impression on a claim this audience
has learned to discount, and carries zero information about what the product
does. Trust here is bought by demonstration — the quote under the number.

## Direction 4 — the invented word

*Coinages that own their search results and mean nothing on day one.*

The generator worked under a hard constraint: this audience's spelling failures
are predictable. **c for /k/ is fatal** (Turkish *c* = /dʒ/), v/b collapses for
Spanish speakers, v/w for Indian speakers, initial *h* vanishes for Romance
readers, and x/q/y/th/doubled letters are coin-flips. Every candidate is built
from p t k m n l r d s f g plus continental vowels.

| Candidate | Verdict |
|---|---|
| **Tesera** | Defended 1st. From *tessera hospitalis* — a token broken in two so the halves can later be matched to prove a bond, which is what a value plus its quote is. Deliberately one *s*, because a doubled letter is unspellable after one hearing: the bend is the argument. |
| **Erga** | Defended 2nd. Greek "works" — quietly corrects the visa/permit category error — plus *erga omnes*. Four unambiguous letters, the cheapest string here to say, type and repeat. Close to "ergo"; short strings are hard to disambiguate in search. |
| **Idonea** | Defended 3rd. Half-transparent: Romance readers get *idóneo* (fit, suitable) free. But it reads as a woman's given name, and "suitable" leans toward the eligibility claim the product refuses to make. |
| Limena | Latin *limen*, threshold — the product's own noun. Killed by two near-misses in audience languages: Spanish *limeña* (a woman from Lima) and Turkish *liman* (harbour). |
| Fontis | "Of the source" — and the launch audience reads *font* first. A name that misfiles itself with your launch audience is worse than one that means nothing. |
| Tekmera | Greek *tekmerion*, proof. Sits in the crowded pharma/biotech naming space. |
| Portalis | Solid and legal (also the jurist of the Napoleonic Code); but "portal" arrives free and is the wrong meaning. |
| Datera | Semi-transparent and pointed at the date stamp; reads as a data-infrastructure vendor, and is probably a storage company. |
| Regulis | Most semantically loaded coinage; listeners will type *Regulus*, and "dry and bureaucratic" is the register the reader is already drowning in. |
| Tolim | Flawless spellability, pure arbitrary mark, highest explanation tax in the set. |
| Nimara | Softest option; warmth is not the trust signal this product sells. |

**Ceiling of the direction, in the generator's own words:** brand equity compounds
with repeat use, and this product is used once or twice in a lifetime. There is
no habit loop for a coined word to accumulate recall in, and long-tail SEO is won
by pages titled with what people type, not by a brand. An invented word is
correct *if the ruleset becomes the thing people cite*, and wasteful if the pages
are all anyone ever finds.

**Landmines the generator steered around, and everyone should:** anything
containing **migra** (*la migra* is immigration enforcement in Latin American
Spanish); anything whose spoken form lands on **sic** (a crude word to a Turkish
listener); any /s/- or /k/-initial coinage ("Citara or Sitara?" is unresolvable
after one hearing).

## The candidate nobody was asked to argue: keep "visa-navigator"

Required by the release gate, and its case must be made as an advantage, not a
default:

- **Switching cost avoided:** two repo names, the sibling `visa-rules`, every
  filename and path in both ledgers, ~50 DECISIONS entries, and the accumulated
  recall inside this project's own history.
- **Against it, and it is decisive:** all four directions independently found
  that the name is *factually wrong*. The product answers questions about work
  and residence permits; a visa is a different instrument. The one thing this
  project sells is not saying inaccurate things about immigration law, and its
  own title does. There is also no external recall to protect — nothing has
  launched and no inbound links exist — so the switching cost is near zero
  today and rises every day after launch.

## Round 1 fork — the human's answer, 2026-09-06

> "I did not like any of them except the dataset direction — but the tool and
> the promise could turn into a name when combined with the dataset. The
> invented word is completely off-base."

- **The dataset direction is the anchor.** Alive.
- **The tool and the promise are dead as pure directions, alive as crossings**
  with the dataset.
- **The invented word is dead.** No coinages in later rounds — Tesera, Erga,
  Idonea, Limena, Fontis, Tekmera, Portalis, Datera, Regulis, Tolim and Nimara
  are buried here, and the direction's own generator supplied the argument:
  brand equity compounds with repeat use, and this product is used once or
  twice in a lifetime.

**Round 2 (recombination) is running** — one Opus pass, deliberately not blind,
briefed with every batch, every ceiling, the landmines and the fork above, to
produce **dataset × tool** and **dataset × promise** intersections. A crossing
only counts if it escapes two ceilings at once; a dataset word glued to a tool
word escapes nothing.

Then the deep critique on Fable in a fresh context, over the round-1 survivors
and the recombinations together. Then availability lookups, on survivors only.
