# S1 — Walking Skeleton · Acceptance scenario

Approved: human, 2026-09-01 (boundary session). Status: written → to be run.

## Seed data

Dataset: a single country (DE), a single route family — EU Blue Card, two thresholds:
- General **€50,700** · quote: "große Blaue Karte EU: 50.700 Euro" · source:
  arbeitsagentur.de · retrieved_at: 2026-09-01 · legal_basis: §18g AufenthG
- Shortage **€45,934.20** · quote: "kleine Blaue Karte EU: 45.934,20 Euro" ·
  same source/date

Criteria: recognised diploma (declaration) · DE job offer · salary band ·
occupation on the shortage list (declaration).

## Steps

1. The site opens locally; on the page a health line: dataset version + the
   newest retrieved_at.
2. The questions are multiple choice; the salary options are EXACTLY "below €45,934.20
   / €45,934.20–€50,700 / above €50,700" — the boundaries derive from the data.
3. Declaration: non-EU · master's (recognised) · software eng. (shortage) ·
   has a DE offer · salary in the middle band.
4. Result (tokens.css): the shortage card **criteria met**; the general card **within
   reach + "up to €4,766"**; on every value quote+source+date; the disclaimer is there.
5. The general threshold is made €52,000 in the dataset and rebuilt: the
   options and the gap change without the code changing.
6. A quote field is deleted and built: it breaks with a schema error that names the field.
7. Baseline: lockfile + audit clean, no secrets, build output structured log.

## Runs

- mock-green: 2026-09-01 — steps 1-7 locally, Claude ran them (browser + build
