## What this slice is for

Everything before this was built for one reader at a time. This slice makes
it public: the dataset as an open repository other people can cite and
contribute to, the site at a name that will not change, and a page per route
that a stranger can land on from a search and trust in the first ten seconds.
It tests the three assumptions nothing else can: A2 (organic traffic comes to
open data), A7 (the gap in open work-permit data is real), A8 (a static tool
plus open data earns links). Launch is the experiment; the slice is the
apparatus.

## Design decisions this slice encodes (approved with this scenario)

1. **The name changes at the tag, in one sweep.** `visa-navigator` →
   `permit-rulebook`, `visa-rules` → `permit-rulebook-data` (not
   `permit-rules`: `permit.io` is a live developer-authorisation company and
   that slug would file the dataset under it on a repo list). The `<title>`,
   masthead, README, package names, and every user-facing string move; the
   ledgers keep their history unedited and gain one line pointing forward.
   Tagline: **"Every route, quoted and dated."** Nothing user-facing may still
   say "Visa Navigator" after the sweep — checked by grep, not by eye.
2. **One page per route, generated from the dataset, never typed.** 23 pages
   at launch. Each renders the route's rules in the order the interview asks
   them, every threshold as the rail module, every quote with its host and
   read date, the preconditions and readings in their blocks, a coverage
   tier, one call to action into the interview pre-scoped to that route, and
   the same country's other routes. **A route page describes; it never rules
   on the reader** — no verdict word appears without answers behind it. The
   page's numbers are the dataset's numbers by construction: a test renders
   every page and compares every amount and quote to the source of truth.
3. **Coverage tier is a declared fact per route, not a computed guess.** Three
   values, from research-01's PathWise harvest: *fully modelled* (every
   deciding condition is asked and every number quoted), *partly modelled*
   (a stated condition is not asked, or a limb is excluded — the page says
   which, from `exclusions.md`), *source only* (the route exists, its rules
   are quoted, nothing is scored). The tier lives in the dataset, is schema-
   enforced, and is shown on the route page and the results card. Absence is
   not allowed: a route with no tier fails validation. **The colour is the one
   token-set addition this slice makes** — it reuses the met/near/hold trio
   rather than inventing a fourth colour, and the mock shows it.
4. **The repository goes public with what a contributor needs on day one.**
   `CONTRIBUTING.md` says how a value changes (quote + date + history, the
   watch flag, the human tier), how a route is added (the schema, the
   exclusions file, the tier), and what a pull request must carry. Issue
   templates carry the Steward triage labels — `bug`, `design-flaw`,
   `new-need` — so feedback lands sorted. The README leads with the licence,
   the tagline and the one-line promise; NOTICE and both LICENSE files ship as
   written at the release gate.
5. **Deploy is static, on GitHub Pages, from the same repository the cron
   runs in.** Cheap default, surfaced: it keeps one vendor and zero cost, the
   daily watch already lives in GitHub Actions, and a static site needs
   nothing else. The custom domain is bound at the tag. Cost: GitHub Pages
   serves no headers we control and no server-side anything — which this
   product has promised never to need. If a CSP or a redirect ever matters,
   Cloudflare Pages is the move and the DECISIONS entry names it.
6. **The daily watch goes live and its first flag is walked by hand.** The
   cron that has been dry-running since v0.6 starts filing issues. The first
   real flag — whatever it is — is read by the human against the source before
   anyone edits a value, so the loop is exercised once with a person in it.
7. **The phone walk happens on the preview, before any announcement.** The
   deploy preview URL is the first thing a real handset sees; the launch post
   is written only after that walk passes.
8. **The disclaimer is the launch's legal wording, and it is one sentence
   everywhere.** The IRCC-style text already on the site becomes the single
   source for the route pages, the README and the launch post — "makes no
   immigration decision and authorities won't consider these results". A1's
   condition (no advice, no verdict on the person) is satisfied by the copy,
   and the route pages add "this page describes the rules; it does not decide
   on you".
9. **The launch post is the README, told once.** A Show HN and the repository
   README carry the same claim in the same words: an open, dated,
   source-quoted work-permit ruleset for four countries, 23 routes, every value
   with its official sentence and the day it was read, checked daily. No
   promise the product does not keep, no count the dataset does not hold. A
   GitHub Sponsors link, small, beside the licence.
10. **v1 is stamped only after the isolated critique.** The full walk by the
    critique agent — every persona, every lens, RUBRIC 1.2, on the deployed
    preview — runs before the tag. Blockers clear or the tag waits; scores are
    recorded, not gated on.

## Seed data

The dataset as of s5f real-green: 23 routes, every value and sentence sourced.
The tier for each route is authored in this slice from `exclusions.md` and the
readings — a curation pass, with the reason for each tier written beside it.

## Steps

1. **A stranger lands cold.** Open `/germany/eu-blue-card-general` with no
   history, as someone who searched "Germany Blue Card salary 2026". In ten
   seconds they can answer: what is the threshold, where does that number come
   from, when was it last checked, and what do I do next. Read the page aloud
   as prose; no line needs the interview to make sense.
2. **The page is the dataset.** Change one threshold in a local copy of the
   dataset, rebuild: the page changes and the test that compares every page's
   amounts and quotes to the dataset passes only when they agree.
3. **No page rules on the reader.** Grep every generated route page for the
   verdict vocabulary — *criteria met*, *within reach*, *not yet*, *you
   qualify* — and find none. The only verdict-shaped text is the call to
   action, which asks rather than tells.
4. **The tier is honest.** Open the three routes with the most exclusions
   (`nl-orientation-year`, `es-highly-qualified`, `de-chancenkarte`): each
   shows *partly modelled* with the excluded limbs named; a route with nothing
   excluded shows *fully modelled*; and removing a route's tier from the
   dataset fails the build.
5. **The name is gone.** After the sweep, `git grep -i "visa navigator\|visa-navigator"`
   over both repositories returns only ledger history and the one forwarding
   line. The `<title>`, the masthead, the README and the launch post say
   Permit Rulebook. The old repository names redirect.
6. **Phone (mandatory, real handset, on the preview).** The interview end to
   end and one route page: nothing overflows 390 px, every tap target reaches
   44 px, the rail labels do not collide, and the coverage tier reads without
   zooming.
7. **The watch files its first issue with a person watching.** Trigger or
   wait for the first live flag; the human reads the flagged source against
   the quote; the outcome — value changed, false alarm, or source moved — is
   recorded in DECISIONS with what the flag said and what was true.
8. **Edge profile (mandatory).** A stranger who lands on a route page for a
   country where they hold a passport that needs no permit (an Irish reader on
   a German page): the page says who it is for before the first rule, and the
   call to action leads to the notice, not to a rejection. And the weakest
   profile through the interview from a route page's call to action: the
   pre-scoped route appears first in the results and every other behaviour
   from s5d and s5e holds.
9. **The isolated critique clears.** The critique agent walks the deployed
   preview; its blockers are fixed and re-verified; its scores are recorded
   with the delta from v0.7's isolated run.
10. **Regression.** All suites green in both repositories; watch coverage both
    ways; quote fidelity `ok`; `human_tier: 0`; `astro check` zero errors on
    24 pages.

## Invariants (property tests)

- **Every amount and every quote on every generated page equals the dataset's**,
  over all routes — the page cannot drift from the source of truth.
- **No generated page contains a verdict word**, over all routes.
- **Every route carries exactly one coverage tier and the tier's stated
  exclusions match `exclusions.md`**, over all routes.
- **No user-facing string in either repository contains the working name**
  after the sweep — a grep-shaped test that stays in the suite.
- Everything from the existing suites, re-run.
