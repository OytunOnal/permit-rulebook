## Seed data

`watch/watchlist.json` in `visa-rules`: one entry per monitored source —
URL, fetch strategy (`html-selector` / `pdf-hash` / `human-tier`), extraction
selector where applicable, and the dataset value ids it backs.
`watch/state.json`: append-only snapshot store (normalized-content hashes +
retrieval timestamps).

## Steps

1. **Coverage is enforced, not promised**: a CI check fails if any
   `source_url` in the dataset is missing from the watchlist, or if the
   watchlist carries an orphan no dataset value references.
2. **`npm run watch`** fetches every non-human-tier source, extracts the
   monitored region, normalizes (whitespace, encoding), hashes, compares to
   state; ndjson log per source; exit code reflects worst outcome. State is
   only written with `--commit`.
3. **Change detected** (fixture: mutate a stored snapshot): the report names
   the source, both hashes, and a quoted context diff; a flag file is written
   to `watch/flags/` (becomes a GitHub issue when CI runs on GitHub — repo is
   not public yet, so real-green here = flag file + one live run against the
   real pages).
4. **Edge lines (mandatory under steward-3):**
   - a source answers 403/bot-wall → status `unreachable`, clearly distinct
     from `changed` — a blocked fetch must never read as "no change";
   - ES PDF byte-identical → quiet; byte-different → `changed (human must
     read)` flag, never an extracted value;
   - network fully down → loud failure with per-source statuses, never a
     silently green run;
   - a `human-tier` source (DE if spike lands there, gesetze re-verification)
     → scheduled reminder flag with `last_verified` age, no fetch attempted.
5. **Cadence**: GitHub Actions cron config (daily) committed and valid;
   actual scheduled firing lands with the public repo in s6 (stated honestly
   as a deferred bit, tracked on the kanban).
6. **Regression**: engine/site untouched; all 51 existing tests stay green.

## Invariants (property tests over generated content)

- Normalization is idempotent: `normalize(normalize(x)) === normalize(x)`.
- Whitespace/encoding-only variations of the same content never flag a
  change; any single-character change in the monitored region always does.
- A watch run without `--commit` leaves `state.json` byte-identical.
- Every dataset `source_url` ⊆ watchlist URLs (checked mechanically, step 1).
