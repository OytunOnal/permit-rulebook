# Bounded and improvable shortfalls never end the interview

A route is retired (and its remaining questions pruned) only on a hard fail:
a definitive miss on a fixed attribute or path choice. Bounded gaps (adjacent
money band, points short) and fails purely on improvable fields (no German
yet, funds not saved yet) keep the route alive so the interview completes and
the route finishes as "within reach" with an exact, field-named gap — and so
leverage steps become provable. We chose this over aggressive pruning after
user testing showed the opposite behavior three times: low funds ended the
interview at three questions, and a no-language explorer saw no language
levers because the questions that would have proven them were never asked.
The cost — a few extra questions on losing paths — buys the product's core
promise: a complete, actionable picture instead of a fast dead end.
