# The project runs on the tracker

From 2026-10-17 the work of Permit Rulebook lives on the GitHub Issues of `OytunOnal/permit-rulebook`: a slice is an issue on a milestone, what only the human can do is an issue labelled `waiting-on-you`, and The Road (`docs/spine/road.html`) is drawn from them. The ledgers (`STATUS.md`, `KANBAN.md`, `DECISIONS.md`, `docs/spine/reviews/`) are kept, frozen, as the history of s1–s37. We moved because Spine v2 reads none of the ledgers while its hooks already ran here, and a project kept in both eras had no guards and a Road that was wrong; the cost is about forty public issues in English, every merge through a pull request, and more of the human's time per slice (`docs/spine/migration-v2.md`, approved by the human 2026-10-17).

## Consequences

- The data repository keeps its own issues (watch flags, data bugs); a slice that changes it names them as `OytunOnal/permit-rulebook-data#N`.
- A decision that is hard to reverse is recorded here, numbered from this one; the rest is on the issue it belongs to.
